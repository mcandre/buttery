Buttery

UsageGitHub

a video editor with manual motion smoothing

Usage

Example

Many source GIFs suddenly come to a jarring halt at the end of the animation. buttery provides tools for smoothing out transitions, creating infinite animation reels.

Before After 
buttery homer.gif

Flags

buttery provides command line flags to manipulate GIFs.

Stitches

-stitch Mirror

By default, buttery smoothes out animations by copying frames in reverse.

As well, the GIF loop count flag is set to infinite.

-stitch Fade

The classic fade-to-black (or orange!) transition. Dream-like.

-fadeColor <#RRGGBB> customizes the transition color.

-fadeRate <float> customizes the transition rate.

Before After 
buttery -stitch Fade -fadeColor "#CC5500" red-panda.gif

-stitch FlipH / -stitch FlipV

Reflecting frames around a horizontal or vertical axis, starting at the animation halfway point in time, is another great way to smooth out transitions.

Before After 
buttery -transparent -stitch FlipH cinnamoroll.gif
buttery -transparent -stitch FlipV cinnamoroll.gif

-stitch PanH / -stitch PanV

Move the camera sideways, wrapping around.

-panVelocity <float> customizes the pixel pan rate.

buttery -stitch PanH red-panda.gif
buttery -stitch PanV red-panda.gif

-stitch Shuffle

Rearrange frames at random, for a chaotic visual flow.

buttery -stitch Shuffle homer.gif

-stitch None

Disable transition stitches.

buttery -stitch None homer.gif

Main sequence Edits

Manipulate frame order.

-loopCount <int>

Set how many times to play the animation.

Loop Count Animation Plays
0 ∞
N N + 1
-1 1 
buttery -stitch None -loopCount 0 homer.gif

-trimStart <n> / -trimEnd <m>

Drop n frames from the start of the animation.

Drop m frames from the end of the animation.

buttery -trimStart 3 -trimEnd 3 red-panda.gif

-trimEdges <n>

Drop n frames from both the start and the end of the animation.

buttery -trimEdges 3 red-panda.gif

-window <n>

Truncate frames beyond the nth.

buttery -window 16 red-panda.gif

-shift <n>

Rotate sequence n frames left.

Negative values shift n frames right.

buttery -stitch None -shift 10 homer.gif
buttery -stitch None -shift -10 homer.gif

-cutInterval <n>

Drop every nth frame of a GIF.

buttery -cutInterval 2 homer.gif

-scaleDelay <float>

Multiply each frame delay by a factor (default 1).

buttery -scaleDelay 2.0 homer.gif

-transparent

Preserve alpha channel.

buttery -transparent cinnamoroll.gif

Metadata

buttery includes metadata query operations.

-check

Validate a GIF for basic file integrity.

buttery -check homer.gif

-getFrames

Get the number of frames in a GIF.

buttery -getFrames homer.gif

-version

Print version identifier.

buttery -version

-help

Print usage menu.

buttery -help
